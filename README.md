## 第一步：你的用途决定了后面所有的取舍

同一个"日本VPS"，四种用途要的东西完全不一样：

**建站、外贸站**要的是稳定。晚高峰不丢包比标称带宽重要得多，一台 100Mbps 但全天跑满的机器，胜过一台 1Gbps 但晚上八点开始抽搐的机器。

**跑应用、开发测试**看 CPU 和内存，顺带要求磁盘 IO 别太拉胯。NVMe 和 SATA SSD 在数据库场景下的差距是能感觉到的。

**日区流媒体、内容业务**里，IP 干不干净是生死线。Netflix、Disney+、TikTok 对 IP 的风控很敏感，配置再高，IP 被标记过也是白搭。

## 第二步：四条硬指标，缺一条都别急着下单

### 线路走向：日本近，不代表快

日本机房离大陆物理距离近，这是天然优势，但线路不对，晚高峰照样卡。联通方向走软银（BBTEC）、移动方向走 CMI 或 Lumen，体验通常不差；纯 NTT 绕路的要掂量。

常见的几条日本回程线路，差别在这里：

| 线路类型 | 谁用着舒服 | 特点 |
| --- | --- | --- |
| 普通国际带宽 | 谁都不太舒服 | 最便宜，晚高峰最易拥塞 |
| 软银 SoftBank（BBTEC） | 联通用户 | 联通直连传统强项，移动电信表现一般 |
| IIJ | 电信用户 | 日本本土大带宽，质量稳 |
| CN2 GIA | 电信用户 | 三网都优化，最稳也最贵 |
| CMI | 移动用户 | 移动直连东京，移动吃红利 |

判断逻辑很简单：**先确认自家宽带出口是哪家运营商，再选线路，最后才比价格**。同一台机器，联通用户跑出 40ms、电信用户跑出 90ms 是常事，这不是商家的问题，是你和机房之间那条路的问题。

### 延迟：超过 120ms 就别信"优化线路"了

华南方向到东京，正常应该在 **50–80ms**；华北、东北会到 **80–110ms** 左右。超过 **120ms** 还自称"优化线路"的，直接跳过。

这个数字可以自己验：下单前问客服要测试 IP，本地 ping 一轮，再跑个回程路由。愿意给测试 IP 的商家，通常对自己的线路有底。

### 流量计费：1TB 实际可能只有一半

这是最容易吃亏的一条。很多日本VPS按**双向计费**，上传下载都算进额度。你以为买了 1TB，实际可用大约一半。跑下载站、做备份同步、上行流量大的业务，一不注意就超。

IP 被风控库标记过，解锁流媒体基本无望，做 TikTok 运营、跨境电商账号也是从一开始就输了。而没有一个像样的退款政策，你连验证的机会都没有——买错了只能吃下去。
